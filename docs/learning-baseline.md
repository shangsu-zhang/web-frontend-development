## 为完整项目补充的知识

- **DOM 与事件**：读取控件、监听 submit/click、更新表格；复杂事件不写进 HTML 属性。
- **数据与服务分离**：页面只调用 `window.parkingService`；Promise/async 用于保留未来 Java 异步接口形状。
- **localStorage 与 JSON**：模拟数据刷新后保留；版本管理、失败提示与重置。不是数据库，也不保存真实身份凭证。
- **fetch 与 HTTP**：仅供 Java 模式适配；当前 mock 模式不向后端发请求。
- **日期、金额与关联校验**：对应 SQL 约束和停车业务，不使用字符串拼接进行金额运算。
- **安全与可访问性**：动态文本转义，表单 label、键盘关闭对话框、错误提示和加载状态。

这些补充集中在服务和公共 UI 层，页面业务仍用原生 HTML、CSS、JavaScript 实现。笔记中的 document.write 是基础演示，本项目用 DOM 更新避免覆盖已加载页面；旧式 bgcolor、align 等表现属性改用外部 CSS，满足课程代码分离要求。
